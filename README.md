Este juego es un trabajo universitario de alumnos de la Universidad Complutense de Madrid. Los miembros del grupo son:
- Víctor Castro Álvarez

## Redes sociales disponibles:
- Twitter/X: https://x.com/CasaDeLasRatas
- Github: https://github.com/Triktor1/La-Casa-de-las-Ratas-PVLI

## Sobre este proyecto

Filthy feathers es un Tower Defense hecho en Phaser 3. El reino de las ratas está siendo invadido por los loros piratas, y deberás usar torres para frenar el avance de las tropas aviares. Este tema viene insipirado del tema "fronteras".
