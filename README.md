## Sobre este proyecto

Filthy feathers es un Tower Defense hecho en Phaser 3. El reino de las ratas está siendo invadido por los loros piratas, y deberás usar torres para frenar el avance de las tropas aviares. Este tema viene insipirado del tema "fronteras".
